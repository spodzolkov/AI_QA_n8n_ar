# Інструкція автоматизації обробки вхідних лідів із форми сайту

## Мета процесу
Автоматично приймати нові заявки клієнтів через Webhook, валідувати контактні дані, оцінювати пріоритет ліда, записувати заявку в таблицю обліку та надсилати сповіщення команді продажів.

## Очікувані кроки воркфлоу

1. **Вхідний тригер (Webhook)**:
   - Метод: `POST`
   - Шлях вебхука: `/incoming-lead`
   - Очікувані поля JSON: `fullName`, `email`, `company`, `budget`, `message`.

2. **Базова перевірка даних (IF)**:
   - Перевірити, що поле `email` не порожнє і містить символ `@`.
   - Якщо `email` відсутній або некоректний — повернути помилку клієнту або завершити обробку з логуванням.

3. **Маршрутизація за бюджетом (IF або Switch)**:
   - Якщо `budget` перевищує VIP-поріг (наприклад, 5000):
     - Надіслати термінове повідомлення у VIP-канал месенджера (Telegram або Slack).
   - Для всіх стандартних заявок:
     - Надіслати звичайне сповіщення у загальний канал продажів.

4. **Збереження заявки**:
   - Записати всі поля ліда + дату отримання у Google Sheets (або CRM).

## Примітка
Деякі деталі (точний месенджер, ID таблиці Google Sheets, точний VIP-поріг у валюті та чи потрібна відповідь клієнту на пошту) необхідно узгодити під час налаштування флоу.
